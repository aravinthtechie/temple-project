# Temple Package

A modern Angular-based temple information and pilgrimage website.

## Features

- Navagraha temple information
- Temple photo gallery
- Temple details
- Pilgrimage tour information
- Booking enquiry
- Multiple language support
- Responsive user interface
- Multiple themes

## Technology Stack

- Angular
- TypeScript
- SCSS
- HTML
- CSS

## Development Server

Install dependencies:

```bash
npm install
```

Run the application:

```bash
ng serve
```

Open http://localhost:4200/ in your browser.

## Build

```bash
ng build
```
